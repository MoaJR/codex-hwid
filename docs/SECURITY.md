# Segurança
Nenhum dado real nesta fase. Sessão HTTPOnly/Secure/SameSite, provedor de identidade, MFA de equipe, limite de tentativas, autorização negada por padrão e auditoria básica de acesso estão implementados. A identidade está ativa em Produção somente para E2E controlado após o provisionamento; APIs e dados clínicos permanecem indisponíveis. Antes de APIs sensíveis: ampliar auditoria sem conteúdo clínico, validar operação e retenção, usar uploads privados e URLs temporárias. Sem cartão completo, rastreadores clínicos ou assinatura eletrônica própria. Segredos somente no ambiente; .env ignorado.
Política pura não é middleware e não autentica usuário. Consumidores devem fornecer apenas escopo obtido de query confiável. Backups, restore, retenção, incidentes e revisão LGPD antecedem operação com dados reais.
O QR Code TOTP é renderizado no navegador sem API externa. A senha de provisionamento é lida sem eco e nunca deve ser passada por argumento ou por chat. A auditoria registra apenas ação, resultado, origem, identidades técnicas e horário.
